📰 News App

A modern and accessible News Application built with Flutter that allows users to discover and explore the latest news from different categories and sources.

The application integrates with a News API to fetch real-time news content and uses Firebase for backend-related services. A key accessibility feature was also implemented to make news content more accessible to blind and visually impaired users through text-to-speech functionality.

---

📱 Overview

The News App provides users with an easy and organized way to browse the latest news.

Users can explore different categories, filter news based on their interests, read complete articles, and listen to news content using the built-in accessibility feature.

The application focuses on:

- 📰 Latest news
- 🔎 News discovery
- 🗂️ Category-based filtering
- 🌎 News from different sources
- 🔊 Accessibility and text-to-speech
- ✨ Shimmer loading effects
- 🔥 Firebase integration
- 📱 Responsive and user-friendly UI

---

✨ Features

🚀 Onboarding

The application includes onboarding screens that introduce users to the main features of the application.

The onboarding experience provides information about:

- News from different sources
- Global news coverage
- Different news categories
- Main application functionality

---

🏠 Home Screen

The home screen provides an overview of the latest and recommended news.

Users can:

- View breaking news
- Explore recommended articles
- Browse different news categories
- Quickly open news articles
- Navigate to other sections of the application

---

🗂️ News Categories

News is organized into multiple categories to make it easier for users to find the content they are interested in.

Example categories include:

- 💼 Business
- ⚽ Sports
- 🎨 Art
- 🏛️ Politics
- 🎬 Entertainment
- 🏥 Health
- 🌎 General News

Users can select a category and view the related articles.

---

🔎 News Filtering

The application provides category-based filtering that allows users to narrow down the displayed news.

Instead of browsing all available news, users can select a specific category and view only relevant articles.

This improves content organization and makes news discovery easier.

---

📰 News Articles

Each news article provides detailed information such as:

- Article title
- Article image
- News source
- Publication date
- Article description
- Full article content
- Source information

Users can open an article and read the complete news content.

---

🔊 Accessibility — Text-to-Speech

One of the key features of the application is its accessibility support.

The application provides a Read News feature that converts written news content into speech.

This allows blind and visually impaired users to listen to news articles instead of relying only on visual reading.

The feature can:

- Read article content aloud
- Help users consume news without reading the screen
- Provide a more accessible news experience
- Improve accessibility for visually impaired users

This feature was implemented as part of the application's focus on inclusive and accessible mobile experiences.

---

✨ Shimmer Loading Effect

The application uses shimmer loading effects to improve the user experience while news content is being fetched from the API.

Instead of displaying a blank screen or a simple loading indicator, shimmer placeholders provide a visual preview of the content layout while data is loading.

The feature helps to:

- Display animated placeholders while news articles are loading
- Maintain the layout structure during data fetching
- Provide visual feedback while waiting for API responses
- Improve perceived loading experience and UI responsiveness

---

The application uses a News API to retrieve news articles from external sources.

The API integration provides:

- Latest news
- Category-based news

The application handles API states including:

- Loading with shimmer placeholders
- Success
- Empty results
- Errors
